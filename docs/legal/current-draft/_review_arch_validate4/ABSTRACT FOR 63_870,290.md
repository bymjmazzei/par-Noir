ABSTRACT OF THE DISCLOSURE

A computer-implemented protocol establishes that user-controlled cloud storage structures act as authoritative for designated protocol state (such as public index membership and recovery vault ledgers) while operator systems host non-authoritative performance caching and coordination services. A portable identity file integrates cleartext post-quantum public key material, an encrypted identity payload, a recovery envelope, and passcode-sealed cryptographic shares. A recovery vault configured on user-owned cloud storage enforces a quorum rule requiring both a threshold number of custodian approvals and at least one approval from an unrevokable custodian, rejecting unauthorized revocation attempts at the protocol execution layer. Upon quorum satisfaction, the system combines shares to reconstruct a master secret, derives a decryption key, and unwraps the recovery envelope to extract and preserve the public key. Alternative key migration pins cloud folder identifiers, re-wraps encrypted digital assets, generates lineage zero-knowledge proofs, and registers network succession records enforcing asymmetrical online rejection and offline local decryption. A non-authoritative performance cache reconciles membership against a user-authored index structure on a background interval while executing immediate purges upon explicit deletion commands.
